# Licensing and release rights

This repository contains the author's research-code notebooks and numeric analysis tables. It does not include third-party imagery, raw PolSAR measurements, hidden credentials, signed forms, private PDFs, checkpoints or feature caches.

- FPSD is publicly listed at https://github.com/Yanhui-Struggle/FPSD, but we have not verified a blanket dataset redistribution license from its maintainers. Do not mirror the images, derived tensors or annotations until rights are confirmed.
- Ultralytics YOLO software and default trained weights have AGPL-3.0 terms (or separate enterprise licensing). Consult https://www.ultralytics.com/license before distribution, choosing repository licensing, or incorporating pretrained weights.
- No author-approved software license has yet been selected. A visible repository without a LICENSE is **not automatically open-source licensed**.
- Before changing visibility, audit complete git history for secrets and third-party content, verify source and checkpoint provenance, select a compatible license, and distinguish checkpoint-based evidence from independent raw-data replication.
